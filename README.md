# Dra. Mely Santos · Odontóloga

1. Abre `.env` y cambia TU-PROYECTO por la URL de tu proyecto Supabase (Project Settings > API > Project URL).
2. Supabase > SQL Editor: pega y ejecuta `supabase/schema.sql`.
3. Supabase > Authentication > Users > Add user: crea tu usuario. Luego ejecuta la última línea comentada del SQL con tu correo.
4. Authentication > Sign In / Providers: desactiva "Allow new users to sign up".
5. `npm install` y `npm run dev`. Panel del personal: enlace "Acceso clínica" del pie (#admin).
